# Método de Copys para Carruseles y Posts — SUPRICOM

## Estructura universal del carrusel

| Slide | Función | Extensión |
|-------|---------|-----------|
| **Portada** | Hook que invita a deslizar | 1 línea título + 1 línea frase |
| **Slides cuerpo** (3–4) | Desarrollo del argumento | 1 línea título + 1–2 líneas frase |
| **Cierre** | Resumen + CTA institucional | 1 línea título + 1 línea frase |

---

## Hook types según el tema

### Si es de un PRODUCTO específico
```
Frase tipo: "[Modelo]. [Feature clave]. [Beneficio directo]."
Gancho: El nombre del producto + lo que lo hace único.
Ejemplo: "BLUETTI AC70P. 1000W de potencia en formato portátil."
```

### Si es de una CATEGORÍA
```
Frase tipo: "[Número] [señales/tipos/formas] de [tema]."
Gancho: Un número + un dolor/concepto.
Ejemplo: "3 señales de que tu cliente necesita protección eléctrica."
```

### Si es de una MARCA
```
Frase tipo: "[Marca]. [Portafolio/posicionamiento]."
Gancho: La marca como solución.
Ejemplo: "FORZA. La marca que los comercios conocen y piden."
```

### Si es COMPARATIVO
```
Frase tipo: "[X] vs [Y]: ¿qué conviene más?"
Gancho: Confrontación directa de dos opciones.
Ejemplo: "BLUETTI vs Planta Eléctrica: ¿qué conviene más?"
```

### Si es por PERFIL de cliente
```
Frase tipo: "Según el perfil de tu cliente: [solución]."
Gancho: Identificación inmediata del buyer persona.
Ejemplo: "4 tipos de clientes que necesitan BLUETTI."
```

### Si es de TENDENCIA / DIAGNÓSTICO
```
Frase tipo: "[Dato/afirmación]. [Implicación]."
Gancho: Un dato + una verdad incómoda.
Ejemplo: "78% de hogares con apagones. 7/10 comercios no venden protección."
```

### Si es de ECOSISTEMA / COMBO
```
Frase tipo: "[Producto A] + [Producto B] = [Beneficio]."
Gancho: La suma es más valiosa que los componentes.
Ejemplo: "El combo que más sube tu ticket: cámara + router + UPS."
```

## Anatomía de cada slide

```
slide: "Nombre corto del slide (max 5 palabras)"
texto: "Título del slide (1 línea, max 12 palabras)"
frase: "Cuerpo del slide (1–2 líneas, max 25 palabras)"
nota: "Indicación visual para el diseñador (opcional)"
```

### Reglas de frase
- **Máximo 25 palabras por frase.** Si ocupas más, el slide se sobrecarga.
- **Una idea por frase.** No mezcles argumentos. Un slide, un concepto.
- **Siempre lenguaje B2B.** "Tu cliente", "tu comercio", "tu negocio".
- **Nunca precios.** Nunca SKUs. Nunca "oferta", "rebajón", "aprovecha".
- **CTA solo en el cierre.** El resto es información consultiva.

## Estructuras de carrusel por tipo de contenido

### Producto (ej: BLUETTI AC70P, MSI Cubi 5, HP M236sdw)
```
Portada: "Nombre del producto. Feature principal."
Slide 2: "Para quién es / perfil de cliente"
Slide 3: "Feature técnica clave + beneficio"
Slide 4: "Feature secundaria + beneficio"
Cierre:  "Disponible en SUPRICOM"
```

### Categoría (ej: protección eléctrica, cámaras, routers)
```
Portada: "N señales/tipos/formas de [tema]"
Slide 2: "Señal/tipo #1 + argumento"
Slide 3: "Señal/tipo #2 + argumento"
Slide 4: "Señal/tipo #3 + argumento"
Cierre:  "Resumen + portafolio disponible en SUPRICOM"
```

### Marca (ej: FORZA, NEXXT HOME, BLUETTI)
```
Portada: "Marca. Frase de posicionamiento."
Slide 2: "Producto estrella + argumento de venta"
Slide 3: "Segundo producto/gama + argumento"
Slide 4: "Tercer producto/gama + argumento"
Cierre:  "Portafolio completo en SUPRICOM"
```

### Comparativo (ej: Router vs Mesh, UPS vs Planta)
```
Portada: "X vs Y: ¿qué conviene más?"
Slide 2: "Opción X: perfil, ventaja, precio relativo"
Slide 3: "Opción Y: perfil, ventaja, precio relativo"
Slide 4: "¿Cuándo elegir cada una?"
Cierre:  "Ambas disponibles en SUPRICOM"
```

### Perfiles de cliente (ej: 4 tipos de clientes que necesitan X)
```
Portada: "N perfiles de cliente que necesitan [tema]"
Slide 2: "Perfil #1: problema + producto ideal"
Slide 3: "Perfil #2: problema + producto ideal"
Slide 4: "Perfil #3: problema + producto ideal"
Cierre:  "Identifica, recomienda, vende. Portafolio en SUPRICOM."
```

### Combo / Ecosistema (ej: cámara + router + UPS)
```
Portada: "El combo que [beneficio]: [productos]"
Slide 2: "El problema de vender suelto"
Slide 3: "La solución: los 3 juntos"
Slide 4: "Argumento de venta del combo"
Cierre:  "Todo disponible en un solo mayorista"
```

## Posts (piezas individuales)

Los posts tienen una sola slide. Estructura:

```
texto: "Mismo título que portada (gancho inicial)"
frase: "3–4 párrafos cortos. Cada párrafo = una idea. Última línea = CTA."
nota: "Descripción visual para el diseñador"
```

### Reglas del post
- **Primer párrafo:** Hook (retoma el gancho de portada).
- **Segundo párrafo:** Desarrollo del argumento principal.
- **Tercer párrafo:** Ampliación o contraargumento.
- **Cuarto párrafo:** Cierre + CTA + cierre institucional.
- **Máximo 4 párrafos.** Si ocupas más, dividelo en carrusel.

---

## Lista de verificación (checklist)

- [ ] Portada tiene hook según tipo (producto/categoría/marca/etc.)
- [ ] Cada slide = una sola idea
- [ ] Frases ≤ 25 palabras
- [ ] Sin precios, SKUs, "oferta", "aprovecha", "revendedor"
- [ ] Lenguaje: "tu cliente", "tu comercio", "tu negocio"
- [ ] Cierre tiene CTA + "SUPRICOM. Tu mayorista de confianza."
- [ ] Para Venezuela: máximo 1 pieza/día, nunca 2 días seguidos
- [ ] Slides de carrusel: 4–6 (portada + 3–4 cuerpo + cierre)
